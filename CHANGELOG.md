# Changelog

## 2.0.0

Ломающие изменения относительно 1.0.6:

- Сборка переведена на TypeScript. Пакет публикует ESM и CommonJS через `exports` (`import` и `require`) и генерируемые типы. `require('moy-nalog')` по-прежнему возвращает сам класс.
- Нужен Node.js 18 или новее. Запросы идут через встроенный `fetch`, зависимость `cross-fetch` убрана.
- `getToken` больше не отправляет лишний `POST /auth/token`, пока авторизация ещё не завершилась.
- Ошибка обновления токена не глотается через `console.error` и доходит до вызывающего кода.
- После неудачного входа `auth()` можно вызвать снова: отклонённый промис не кэшируется.

Публикация в npm выполняется из GitHub Actions по тегу `v*` через Trusted Publishing (OIDC), без токена `NPM_TOKEN`.
